# Phone and PWA

The admin app is built to work on phones and tablets, and you can install it like an app. In your browser,
choose **Add to Home Screen** or **Install**.

![The inbox on a phone](../images/phone-dark.png#only-dark)
![The inbox on a phone](../images/phone-light.png#only-light)

* **Offline.** The app itself opens without a connection, but viewing feedback and making changes needs the network. Loupebox never stores feedback or sign-in details on the device for offline use.
* **Updates.** A new release is picked up the next time you open a page.
